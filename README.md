# OpenCV Projects

A collection of OpenCV projects demonstrating image processing and computer vision using Python.

## Features
- Read and display images
- Resize images
- Crop images
- Rotate images
- Draw shapes and text
- Image transformations

## Technologies Used
- Python
- OpenCV
- NumPy

## Installation

```bash
pip install opencv-python numpy
```

## Run

```bash
python image_resize.py
```
